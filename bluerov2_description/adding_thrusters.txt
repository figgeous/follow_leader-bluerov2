# Instructions for Adding Two More Thrusters to the BlueROV2

This guide explains how to modify the BlueROV2 description package to add two additional thrusters (thruster7 and thruster8) to the standard 6-thruster configuration.

## 1. Modify the URDF/XACRO Files

### Step 1: Edit the thrusters.xacro file

Open `urdf/thrusters.xacro` and add the definitions for the two new thrusters at the end of the file, before the closing `</robot>` tag:

```xml
<xacro:thruster thruster_id="7">
  <origin xyz="${thruster7_x} ${thruster7_y} ${thruster7_z}" rpy="${thruster7_roll} ${thruster7_pitch} ${thruster7_yaw}"/>
</xacro:thruster>

<xacro:thruster thruster_id="8">
  <origin xyz="${thruster8_x} ${thruster8_y} ${thruster8_z}" rpy="${thruster8_roll} ${thruster8_pitch} ${thruster8_yaw}"/>
</xacro:thruster>
```

### Step 2: Define the thruster position variables

At the top of the `thrusters.xacro` file, add the position and orientation variables for the new thrusters. You can place these after the existing property definitions:

```xml
<!-- Thruster 7 position and orientation -->
<xacro:property name="thruster7_x" value="0.0"/>
<xacro:property name="thruster7_y" value="0.0"/>
<xacro:property name="thruster7_z" value="0.0"/>
<xacro:property name="thruster7_roll" value="0.0"/>
<xacro:property name="thruster7_pitch" value="0.0"/>
<xacro:property name="thruster7_yaw" value="0.0"/>

<!-- Thruster 8 position and orientation -->
<xacro:property name="thruster8_x" value="0.0"/>
<xacro:property name="thruster8_y" value="0.0"/>
<xacro:property name="thruster8_z" value="0.0"/>
<xacro:property name="thruster8_roll" value="0.0"/>
<xacro:property name="thruster8_pitch" value="0.0"/>
<xacro:property name="thruster8_yaw" value="0.0"/>
```

### Step 3: Decide on thruster rotation direction

Determine whether the new thrusters should rotate clockwise or counter-clockwise. In the existing configuration:
- Thrusters 1, 2, and 5 rotate clockwise
- Thrusters 3, 4, and 6 rotate counter-clockwise

Modify the conditional statements in the thruster macro to include your new thrusters:

```xml
<xacro:if value="${thruster_id in [1,2,5,7]}"> <!-- Add 7 here if it should be clockwise -->
  <mesh filename="${prop_mesh_cw}"/>
</xacro:if>
<xacro:unless value="${thruster_id in [1,2,5,7]}"> <!-- Add 7 here if it should be clockwise -->
  <mesh filename="${prop_mesh_ccw}"/>
</xacro:unless>
```

And similarly for the axis direction:

```xml
<xacro:if value="${thruster_id in [1,2,5,7]}"> <!-- Add 7 here if it should be clockwise -->
  <axis xyz="1 0 0" />
</xacro:if>
<xacro:unless value="${thruster_id in [1,2,5,7]}"> <!-- Add 7 here if it should be clockwise -->
  <axis xyz="-1 0 0" />
</xacro:unless>
```

## 2. Update the Launch Files

### Step 1: Modify upload_bluerov2_launch.py

Open `launch/upload_bluerov2_launch.py` and update the thruster loop to include the new thrusters:

```python
# thrusters
for thr in range(1, 9):  # Change from 7 to 9 to include thrusters 7 and 8
    thruster = f'thruster{thr}'
    gz_thr_topic = f'/{ns}/{thruster}/cmd'
    bridges.append(GazeboBridge(gz_thr_topic, f'cmd_{thruster}', 'std_msgs/Float64', GazeboBridge.ros2gz))
```

### Step 2: Update manual.yaml for slider control

If you want to control the new thrusters manually with sliders, add entries for them in `launch/manual.yaml`:

```yaml
cmd_thruster7:
    type: std_msgs/msg/Float64
    thrust:
        min: -30
        max: 30
        to: data
cmd_thruster8:
    type: std_msgs/msg/Float64
    thrust:
        min: -30
        max: 30
        to: data
```

## 3. Adjust Physical Properties (Optional)

Depending on the placement and purpose of the new thrusters, you might need to adjust the physical properties of the BlueROV2:

1. If the additional thrusters significantly change the mass distribution, update the inertia values in `bluerov2.xacro`.
2. If the buoyancy is affected, adjust the buoyancy parameters.

## 4. Thruster Placement Considerations

When deciding on the final values for the thruster positions and orientations, consider:

1. **Maneuverability**: Position thrusters to enhance specific movement capabilities (e.g., lateral movement, yaw control).
2. **Stability**: Ensure the thruster configuration maintains vehicle stability.
3. **Interference**: Avoid placing thrusters where their flow might interfere with each other or with sensors.
4. **Symmetry**: Consider maintaining symmetry for predictable behavior.

## 5. Testing Your Configuration

After making these changes:

1. Launch the simulation with your modified BlueROV2:
   ```bash
   ros2 launch bluerov2_description upload_bluerov2_launch.py
   ```

2. Verify that all 8 thrusters appear in the correct positions in Gazebo.

3. Test thruster control by publishing to the thruster command topics:
   ```bash
   ros2 topic pub /bluerov2/cmd_thruster7 std_msgs/msg/Float64 "data: 10.0"
   ros2 topic pub /bluerov2/cmd_thruster8 std_msgs/msg/Float64 "data: 10.0"
   ```

4. If using sliders, launch with the sliders argument:
   ```bash
   ros2 launch bluerov2_description upload_bluerov2_launch.py sliders:=true
   ```
